지표 정의 — 활용률·집계 공통

환경 성능 추이·대시보드 화면 수치의 계산 방식·표본·시간 범위 정의. right-sizing 분류, 통계(평균·p95·peak), 운영 신호 임계는 아래 "분류 기준"·"운영 신호 임계" 절 참조.

개념 정의
단일 집계 원칙모든 차트(환경·선택·서버상세·대시보드)는 한 규칙으로 계산 — 각 시점마다 그 시점 데이터를 보낸 서버로 환경값 1개(쓴 양 / 가진 양)를 만들고, 버킷은 그 시점값들의 avg/max/p95. 대상(전체·선택 N대·1대)만 다르고 산식은 동일 — 선택 1대 = 서버 상세와 같은 값.
capacity-weighted 평균활용률(%)은 서버별 단순 산술평균이 아니라 자원 총량으로 가중 — 큰 서버가 더 큰 비중. CPU=각 서버 (사용률 * 코어수) 합 / 코어수 합, 메모리=sum(used_kb) / sum(total_kb), 디스크=전 mount sum(used) / sum(total). 작은 서버에 희석되지 않아 환경 실제 활용을 반영. (예: 64코어 90% + 2코어 10% -> 단순평균 50% 가 아니라 가중 87.6%.)
현재 스냅샷 vs 윈도우"현재" 표기 지표(실시간 메트릭)는 각 서버 최신 1개 스냅샷 집계. 차트·보고서의 윈도우 지표는 선택 구간 시계열 — 보고서 표준 7일, 대시보드 현황 카드는 최근 6시간 ("평가 윈도우" 절).
집계 대상그 시점 데이터를 보낸 서버만 집계 — 온라인/오프라인을 따로 판단하지 않는다(데이터 유무가 곧 필터). 최신 스냅샷이 신선(now-TTL 이내)하면 포함, stale/없음이면 자동 제외.
구간 · 버킷 · 앵커구간(time range)=조회 시간 폭(15분~30일). 버킷=구간별 자동 집계 단위(분해력 — 구간이 길수록 버킷도 커짐). 앵커=기준 종료 시각(과거 구간 조회). 한 화면의 모든 차트에 동일 적용.
avg · maxavg=버킷 안 평균선(중심 경향). max=버킷 안 최댓값 ghost 선(burst 강도). 토글로 표시.
디스크 총량물리 디스크(size) 합 — 물리 디스크 미발행 OS(Windows)는 데이터 볼륨 mount 총량 합으로 대체. 인벤토리·세부 서버 목록·보고서·Export 동일 산식.

환경 성능 추이 지표

환경 전체(전 서버) 집계 — 집계 방식은 지표 성격에 따라 셋. 활용률(%) 지표는 capacity-weighted(자원 총량 가중 Σnum/Σden, 큰 서버 비중 큼), 처리량(I/O·PPS) 지표는 합산(SUM — 절대 총량이라 가중 평균 무의미), 로드는 코어 정규화(Σload/Σcpu_cores). 아래 "집계" 컬럼이 그래프별 방식.

지표 집계 정의
현재 평균 활용률capacity-weighted온라인 서버 최신 스냅샷의 CPU/메모리/디스크 평균(실시간 메트릭). 디스크는 전 mount 통합(서버별 worst mount 아님).
현재 부하 상위서버별 값자원별(CPU/메모리/디스크/로드/스왑) 서버 현재값 내림차순 상위(실시간 메트릭). 평균과 달리 개별 호스트 랭킹 — 호스트명 클릭 시 상세로 이동.
CPU 사용률capacity-weighted전 서버 시점 평균(Σjiffies delta — 코어 수 내재). 100%=전 코어 포화.
CPU 분류capacity-weightedCPU 시간을 user(응용)·system(커널)·iowait(디스크 대기)로 분해한 비율. iowait 높으면 디스크 병목.
코어당 로드코어 정규화15분 로드를 코어 수로 정규화 — sum(load_15m) / sum(cpu_cores). 1.0 = 코어당 run queue 1(포화). 절대 load 동등평균은 코어 수 다른 서버 혼재 시 왜곡되므로 정규화.
메모리 사용률capacity-weightedΣused_kb / Σtotal_kb. cached·buffers 는 회수 가능이라 가용으로 간주.
메모리 구성capacity-weighted전체 메모리 대비 Used·Available·Cached·Buffers 비율.
스왑 사용률capacity-weighted스왑 총량 대비 사용량(swap 미설정 서버 제외). 사용 자체가 메모리 포화(page-out) 신호.
물리 계층 I/O합산(SUM)물리 디스크 IOPS 합산(Read/Write). LVM·파티션 계층 중복 집계 제외. 처리량 총량이라 가중 무의미.
디스크 I/O 처리량합산(SUM)물리 디스크 read+write 처리량 합산(kB/s). IOPS 와 함께 디스크 대역 산정 입력.
파일시스템 사용량capacity-weighted전 mount 통합 Σused / Σtotal (가상 mount 제외).
네트워크 I/O합산(SUM)물리 인터페이스 트래픽 합산(RX/TX, bytes/s). 가상·bond/bridge master 이중계산 제외.
네트워크 PPS합산(SUM)물리 인터페이스 패킷 처리량 합산(RX/TX).

대시보드 지표

지표 정의
환경 요약등록 서버 총 vCPU·메모리·디스크 용량 합 + 온라인/오프라인 수 + OS·역할 분포.
환경 평균 활용률전 서버 capacity-weighted 평균 — 최근 6시간 윈도우. 실시간 메트릭의 "현재 평균 활용률"과 같은 가중 방식이나, 시간 범위가 현재 스냅샷이 아닌 윈도우 통계.
자원 적정성 분포USE Method 6분류(리소스 부족·과다 프로비저닝·유휴·종료 권장·정상·표본 부족) 호스트 수 — 최근 6시간 윈도우. 분류 임계는 "분류 기준" 절.
자원 부족 호스트under_provisioned 호스트 + 발화 trigger(스왑·CPU·메모리·Load·디스크). 임계는 "임계 카탈로그" 절.
운영 신호수집 끊김(gap)·OS 지원 종료(os_eol)·에이전트 불안정(재시작 빈도). 임계는 "운영 신호 임계" 절.
환경 부하 추이최근 6시간 capacity-weighted CPU·메모리 시계열(15분 버킷). 수집 이력이 있는 범위만 동적 x축(빈 구간 제외) — 윈도우보다 데이터가 짧으면 있는 기간으로 정규화, 버킷 간격만 윈도우 기준 고정. 서버 상세 차트(윈도우 전체를 빈 구간 포함 표기)와 x축 범위가 다를 수 있음.
네트워크 토폴로지L3 subnet 공동 소속 추론 그래프(노드=subnet/host). 인벤토리 IP 기반 추론이며 실측 도달성(reachability)은 아님 — 방화벽·VLAN 격리 미반영. docker·libvirt 등 호스트 내부 가상 네트워크와 IPv6는 제외. 사설 IP 대역이 서로 다른 네트워크에서 중복되면 한 서브넷으로 합쳐 보일 수 있음.
