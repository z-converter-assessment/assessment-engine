서비스 뱃지

서버 목록·상세·환경 보고서의 "구동 서비스"에 표시되는 카테고리 뱃지. 호스트가 구동하는 워크로드를 서비스 이름·실행 파일(comm)·listen 포트 신호를 종합해 아래 카테고리로 분류한다 (정밀도 순 name -> comm -> port). 같은 카테고리가 여러 개면 "db 2" 처럼 개수를 병기하고, 컨테이너 런타임은 docker+containerd 가 함께 떠도 호스트당 1로 집계한다.
