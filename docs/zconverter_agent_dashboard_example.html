작업 등록 및 Agent 실행 플로우

1. Web UI

서버 체크박스 선택 후 ZConverter Install 버튼 클릭. ZDM 주소를 입력받는다.

→

2. FastAPI

선택 서버별 task 생성. DB에는 작업 이력, Redis에는 pending task를 등록한다.

→

3. Redis

선택 서버 기준의 pending task를 Redis에 등록하고 Agent가 이후 주기에서 확인할 수 있도록 한다.

→

4. Agent

주기적으로 metrics를 MQ에 publish한 뒤 HTTP GET으로 자기 서버의 task 존재 여부를 확인한다.

→

5. Execute & Report

task가 있으면 curl → tar → install.sh 실행. 결과는 FastAPI 또는 MQ로 보고한다.

Agent는 주기적으로 metrics 및 상태 정보를 MQ로 전송하고 이후 HTTP GET 기반으로 작업 존재 여부를 확인한다. 웹에서는 서버 선택 후 작업을 등록하며 Redis 및 DB를 활용하여 작업 상태와 실행 흐름을 관리하는 구조를 가정한다.

ZConverter Install 작업 등록

선택한 서버에 설치 작업을 등록합니다. Agent는 다음 주기에서 HTTP GET으로 해당 서버의 task를 확인하고, 작업이 있으면 지정된 ZDM 주소를 기준으로 설치 스크립트를 수행합니다.
