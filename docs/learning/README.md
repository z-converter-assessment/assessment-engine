# 학습 자료 관리 계약

본 디렉토리는 이 저장소를 예제로 삼아 정리한 학습 자료의 자리다. 대상 독자는 이 저장소를 만드는 사람 자신이고, 목적은 도구와 플랫폼이 어떻게 도는지를 되찾는 것이다.

## 성격

`docs/` 의 다른 계층과 성격이 다르다. reference·guides·explanation 은 코드를 따라 갱신하는 라이브 문서이고, decisions 는 이 저장소의 결정을 남기는 불변 이력이다. 학습 자료는 둘 다 아니다 — 저장소 밖 지식이 본문이고, 저장소는 그 지식이 실물로 어떻게 나타나는지 보여주는 예제로 쓰인다.

| 항목 | 규정 |
|------|------|
| 갱신 의무 | 없음. 시점 스냅샷이다 |
| 기준 시점 표기 | 의무. 문서 머리에 날짜와 커밋 |
| 인용 방향 | 학습 자료가 코드·영구 문서를 가리키는 것은 허용. 그 반대는 금지 |
| 인덱스 등재 | `docs/README.md` 지도와 `.claude/CLAUDE.md` 문서 인덱스 표에 개별 파일을 올리지 않는다 |

인용을 단방향으로 묶는 이유는 라이브 문서의 "사실 하나 = 문서 하나" 원칙을 지키기 위해서다. 학습 자료는 저장소 사실을 시점 스냅샷으로 다시 서술하므로, 라이브 문서가 이쪽을 가리키면 정본이 둘로 갈라진다.

갱신 의무가 없다는 것은 낡은 서술을 방치한다는 뜻이 아니라, 코드가 바뀔 때마다 따라 고치지 않는다는 뜻이다. 다시 읽다가 코드와 어긋난 곳을 발견하면 그 자리에서 고치고 기준 시점을 갱신한다.

## 계층 3층

한 주제를 이해하려면 추상화 수준이 다른 사실 셋이 필요하다. 이것들을 섞어 쓰면 어느 것이 도구를 바꿔도 남는 지식이고 어느 것이 이 저장소 사정인지 구분이 안 된다.

| 층 | 담는 것 | 수명 |
|----|---------|------|
| L1 플랫폼·프로토콜 | 커널·표준·수학이 정한 것. 도구를 갈아치워도 그대로다 | 가장 길다 |
| L2 도구·생태계 | 특정 도구가 L1 위에 세운 규약과 기본값 | 도구 수명 |
| L3 이 저장소의 조합 | L1·L2 의 어느 성질 때문에 이 선택을 했는가 | 가장 짧다 |

예를 들어 netfilter 의 hook 과 table 격자는 L1, docker 가 그 격자에 DNAT 규칙을 까는 방식은 L2, Redis 를 루프백에만 바인딩한 이유는 L3 다.

층은 절의 주제로 가른다. L1·L2 절이 이 저장소의 실물을 예시로 끌어오는 것은 층 혼재가 아니다 — 주제가 일반 원리고 저장소는 그것을 눈에 보이게 하는 예시다. 저장소의 선택 자체가 주제인 절만 L3 다.

## 작성 규칙 4개

1. 한 문서 = 한 주제. 문서 안에서 절을 L1 -> L2 -> L3 순으로 배치하고 층을 뒤섞지 않는다. 앞 층을 모르면 뒤 층이 이해되지 않는 순서라 읽는 순서가 곧 층 순서다. 전체 그림을 먼저 세우는 오리엔테이션 절만 예외로 맨 앞에 둘 수 있다.
2. 같은 층의 같은 사실을 두 문서에 쓰지 않는다. 다른 문서가 이미 세운 개념은 그 문서의 절을 가리키고 재설명하지 않는다. 용어표는 예외로 문서마다 둔다 — 읽는 자리에서 바로 풀려야 한다.
3. L3 는 사실 카탈로그가 아니라 인과 연결이다. "무엇이 그렇게 되어 있다" 는 이해에 필요한 최소만 적고, "L1·L2 의 어느 성질이 그 선택을 강제했는가" 가 본문이다. 설정값 전수 목록은 영구 문서와 코드가 정본이므로 옮겨오지 않는다.
4. 실측값은 실측임을 밝히고 뽑은 시점을 적는다. 구조를 실물로 보여주는 값(digest·바이트 수·인증서)은 낡아도 학습 가치가 남지만, 현재 상태로 읽히면 안 된다.

## 초안에서 격상까지

즉흥적으로 쓰기 시작한 자료는 `docs/temp/` 에 둔다. 전체 틀이 잡히기 전에는 어느 층에 속하는지도 정해지지 않으므로 위 규칙을 적용할 수 없다.

격상은 세 가지를 처리하는 작업이다.

- 계층 분리 — 뒤섞인 L1·L2·L3 를 절 단위로 가른다
- 중복 제거 — 다른 학습 문서가 이미 세운 개념은 포인터로 바꾼다
- 실측 대조 — 초안이 쓰인 뒤 코드가 바뀌었는지 확인하고 낡은 서술을 정정한다

격상이 끝나면 `docs/temp/` 의 원본을 지운다.
