# 0001. 코딩 에이전트 공용 정본

## Status

Accepted

## Context

프로젝트 지침과 작업 절차가 Claude Code 자동 발견 경로에 직접 들어 있으면 다른 코딩 에이전트가 같은 규약과 기능을 사용하려면 내용을 복제해야 한다. 복제본은 서로 다른 시점에 수정되어 규약과 절차가 갈라질 수 있다.

도구별 파일을 같은 내용으로 유지하는 방식, 한 파일을 심링크로 연결하는 방식, 공용 파일과 얇은 자동 발견 어댑터를 분리하는 방식을 검토했다. 도구별 복제는 정본이 여러 개가 되고, 심링크는 파일 처리와 배포 환경에 따라 동작이 달라진다. 프로젝트 플러그인 설정은 설치된 도구와 플러그인에 실행이 종속된다.

## Decision

프로젝트 지침은 루트 `AGENTS.md`, 작업 스킬과 감사 절차는 `.agents/`를 정본으로 둔다.

도구별 자동 발견 경로에는 공용 정본을 읽도록 지시하는 얇은 일반 파일만 둔다. Claude Code는 루트 `CLAUDE.md`와 `.claude/` 어댑터를 사용한다. 공용 기능은 심링크, 도구별 명령 문법, 프로젝트 플러그인 설정에 의존하지 않는다.

## Consequences

모든 코딩 에이전트가 같은 파일을 읽어 동일한 규약과 절차를 적용한다. 새 도구를 지원할 때는 정본을 복제하지 않고 자동 발견 어댑터만 추가한다.

공용 절차를 바꿀 때는 `.agents/`를 먼저 수정하고 도구별 어댑터가 계속 정본만 가리키는지 검증해야 한다. 도구별 플러그인 편의 기능은 개인 설정으로만 사용할 수 있다.
