# 공용 에이전트 자원

이 디렉토리는 특정 코딩 에이전트에 종속되지 않는 프로젝트 공용 자원이다.

구성 요소는 3개다.

1. 루트 `AGENTS.md`는 모든 에이전트가 따르는 프로젝트 규약의 정본이다.
2. `skills/`는 요청과 변경 유형별 작업 절차의 정본이다.
3. `reviewers/`는 코드와 문서를 독립 검토하는 읽기 전용 감사 절차의 정본이다.

코딩 에이전트는 루트 `AGENTS.md`와 이 디렉토리를 직접 사용한다. 도구별 자동 발견 경로는 공용 파일을 가리키는 얇은 어댑터만 두며 파일 간 심링크는 사용하지 않는다.
